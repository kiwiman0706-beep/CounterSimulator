# CounterSimulator — 受付カウンター断面シミュレータ

クリニックの受付を「スタッフは座り、患者は立つ」2段構成にして床面積を節約するとき、
デスク高・カウンター高・その段差に吊るLCDの寸法がどこで破綻するかを、
身長を入れ替えながら断面で確認するための1ファイルツールです。

`index.html` をブラウザで開くだけで動きます（ビルド不要・通信は Google Fonts のみ）。

## できること

- **断面図** と **3Dビュー** の切り替え（3Dは依存ライブラリなしの自前レンダラ）
- 3Dは俯瞰・患者側・真横に加えて **患者の目線／スタッフの目線** カメラを用意。
  ドラッグで回転（目線モードでは見回し）、ホイールで拡大
- スタッフ／患者の身長、患者の姿勢（立位・車いす）を変えて断面を描画
- デスク高・カウンター高・座面高・各奥行・天板の持ち出し・天板厚・モニターサイズ／傾斜を調整
- スタッフ側（座位）／患者側／段差・LCD・視線の3系統で自動判定（最適・許容・要調整）
- 身長別の適合表（スタッフ 1400〜1900mm、患者 1300〜1900mm）
- 「この2人に合わせる」で座面・デスク高・カウンター高を人体寸法から逆算

## 判定に使っている主な基準

| 項目 | 目安 |
| --- | --- |
| デスク高 − 座位肘高 | −30〜+30mm |
| 座面高 − 膝窩高（靴25mm） | ±20mm |
| 天板下の太もも逃げ／膝高クリアランス | 20mm 以上（余裕 40mm） |
| モニター上端 | 座位の目線以下 |
| モニター中心への俯角 | 10〜35° |
| 視距離 | 500〜800mm |
| カウンター高 − 立位肘高 | −120〜−30mm（記入面） |
| マイナ受付機の画面中心 | 肘高〜目線−150mm |
| 患者→スタッフの見下ろし角 | 25° 以下 |
| 座ったままカウンター天板に届く | 上肢長(0.330H)+前傾130mm 以内 |
| 持ち出し下を除くデスク開口奥行 | 450mm 以上 |
| 持ち出しの陰で見えない画面上部 | 0mm（15mm以内が最適・45mmまで許容） |
| プリンターを避けて座れる間口 | 700mm 以上 |
| 車いす対応（別位置の下がりカウンター） | 天板 740mm 以下／下部有効高 650mm 以上／奥行 450mm 以上 |

## 人体寸法の推定

身長 H に対する比率で算出しています（日本人成人の平均的な比率に基づく概算、個人差 ±3% 程度）。

- 立位：眼 0.933H ／ 肩 0.818H ／ 肘 0.630H
- 座位（座面より上）：眼 0.450H ／ 肩 0.365H ／ 肘 0.145H ／ 座高 0.520H ／ 大腿厚 0.085H
- 床から：膝窩 0.255H ／ 膝 0.285H ／ 臀部-膝 0.265H ／ 上肢長 0.330H

覗き見判定は、患者の目とモニター上端を結ぶ線分が天板・幕板の矩形と交差するかで判定しています。

## 断面のモデル

```
        [マイナ受付機]
      ┌─────────────┐  ← カウンター天板（スタッフ側へ持ち出し可）
   │ ▓ 幕板         │
   │ ▓ [LCD]        │  ← 段差 = カウンター高 − 天板厚 − デスク高
┌──┴─▓──────────────┘
│ デスク天板            ← スタッフ側（座位）
│ [PC] [プリンター]
└──────────────────── 床
```

## 3Dビューの実装

外部ライブラリを使わず、Canvas 2D 上に自前の透視投影で描いています。

- 立体は軸平行ボックスの集合。各面を最大340mmのタイルに分割し、
  タイル重心の視点座標での深度で奥から描画（ペインタ法）。
  分割しないと大きな面が手前の小さな面（＝壁面のLCD）を覆ってしまいます。
- 面の外向き法線（面重心 − ボックス重心）で裏面を除去し、
  同じ法線で陰影を付けています。タイルの境界線は元の面の外周だけを描画。
- 近クリップ面で多角形・線分をクリップしているので、目線カメラで
  什器の内部に入っても破綻しません。
